# Задание

Подготовьте контракт API возвратов, проверьте по нему сервис и исправьте найденные несоответствия.

## 1. Опишите контракт

Прочитайте [требования](requirements.md) и заполните `contracts/openapi.yaml` в формате OpenAPI 3.0.3.

Опишите все операции, параметры пути и запроса, обязательный заголовок создания заявки, тела запросов, ответы и ошибки. В схемах укажите обязательные поля, типы, форматы, ограничения и перечисления. Для `POST /refunds` опишите оба успешных кода и заголовок `Location`.

Зафиксируйте бизнес-правила в описаниях операций. Условие доступного остатка и переходы между статусами нужно дополнительно проверить сценарными тестами: одна схема ответа их не докажет.

Контракт составляется по требованиям. Поведение исходного сервиса не является образцом.

## 2. Проверьте сервис

Сначала убедитесь, что спецификация корректна:

```bash
python -m openapi_spec_validator contracts/openapi.yaml
```

Затем запустите контрактные проверки Schemathesis и сценарные проверки pytest:

```bash
python -m pytest tests/test_contract.py
python -m pytest -m assignment
```

Разберите падающие проверки. Для каждого несоответствия сохраните минимальный запрос, ожидаемый результат по требованиям и фактический ответ.

Дополните тесты, если для найденной проблемы нет отдельного воспроизводимого сценария. Проверяйте и ошибочные запросы, и разрешённые действия: запрет всех операций не считается исправлением.

## 3. Исправьте реализацию

Устраните причины несоответствий в `refund_api/`. Контракт и проверки должны оставаться согласованными с требованиями.

После исправлений запустите весь набор:

```bash
python -m pytest
```

Для изменений данных используйте изолированные базы. Тесты должны воспроизводиться без ручной очистки SQLite между запусками. Порядок запуска тестов не должен влиять на результат.

## 4. Подготовьте результат

Сдайте репозиторий или ссылку на ветку с:

- заполненным `contracts/openapi.yaml`;
- исправленным сервисом;
- контрактными и сценарными тестами;
- отчётом по [шаблону](report-template.md);
- обновлённым README с командами запуска и проверки.

## Что проверяется

| Часть | Критерий |
|---|---|
| Спецификация | OpenAPI 3.0.3 проходит валидацию и описывает все требования к API |
| Контрактные проверки | Schemathesis использует подготовленный файл и проверяет коды, заголовки и схемы ответов |
| Бизнес-сценарии | Тесты проверяют идемпотентность, доступную сумму, переходы статусов и пагинацию |
| Исправления | Причины ошибок устранены, разрешённые операции работают |
| Воспроизводимость | Чистая установка и тесты выполняются по README |
| Отчёт | Для несоответствий есть запросы, причины, изменения и регрессионные тесты |

Описание структуры тестов и полезные ссылки — в [testing.md](testing.md).
